**CatX-UI** is a maintained downstream fork of
[MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui). The repository preserves
the upstream panel and Xray boundaries while adding independently gated Policy,
Traffic Control, Insight, and Operations capabilities.

This directory contains inherited upstream documentation material and CatX
repository guidance. It is not an independently published official CatX
documentation site. For the stable public contract, use the [root
README](https://github.com/CatCodeArbelin/CatX-UI/blob/main/README.md) and [stable
release notes](https://github.com/CatCodeArbelin/CatX-UI/blob/main/docs/29_STABLE_RELEASE_NOTES.md).

## Product layers

- **Policy** — policies, groups, schedules, domain/category decisions, and
  explainable simulation.
- **Insight** — Activity, traffic history, DNS Intelligence, and metadata-only
  destination evidence.
- **Traffic Control** — capability-dependent quotas, windows, speeds, and
  soft-throttle workflows.
- **Operations** — audit, webhooks, metrics, self-service, fleet, backup,
  rollback, and updater safety.

<Callout type="warn">
  Generic Xray-user kernel attribution is unsupported. Traffic Control must
  report capability-dependent supported, degraded, or unsupported state. CatX
  does not use TLS MITM or collect decrypted HTTP content, cookies,
  Authorization headers, credentials, passwords, or messages.
</Callout>
